# 角色视觉规范

两个角色都是参数化 SVG 图元（`assets/engine/chars.js`），零图片素材。
改颜色改 `K` / `X` 两个常量对象；改造型改几何参数，不要去挪几百个坐标。

## 配色：为什么必须分家

改版前两人都是橙（考考卫衣 `#F5813C`、小熹毛色 `#F2603C`），同框时剪影糊成一块，
远看分不清谁是谁。改版后：

| | 考考 | 小熹 |
|---|---|---|
| 色相 | 205°（湖蓝） | 15°（狐狸橙） |
| 主色 | `#3E7CB8` | `#F2603C` |
| 关系 | 冷 | 暖 |

任何背景上都是「冷色的人 + 暖色的狐」。**考考身上不允许出现橙色**——暖色只留 6% 的芥末黄做点缀。

## 考考

```js
buildKao(EL, expr, parent)   // expr: idle | silly | wow | talk
```

- 局部原点在脚底中心，全高 560，发尖到 -590，最宽 ±190（含手）
- 五官锚点：眉 -476、眼 -450、鼻 -416、嘴 -378、下巴 -338
- 招风耳画在头**之前**，中心 ±104（头 rx 只有 92）、外张 18°，让头压住内侧一半
- 眼睛是扁椭圆 + 一条上睑压线（控制点 cy-22，弧顶正好压在眼白上缘）——这是「单眼皮细长眼」的全部秘密
- `talk` 的嘴是一个可缩放组；引擎每帧改 `transform: translate(0 -378) scale(1 k) translate(0 378)`

## 小熹

```js
buildXi(EL, { view, expr, tail }, parent)
```

| 字段 | 取值 | 说明 |
|---|---|---|
| `view` | `front` / `q34` / `side` / `back` | 正面 / 三分之二 / 侧面 / 背面 |
| `expr` | `idle` / `happy` / `wow` / `think` / `giggle` / `scope` / `talk` | 表情 |
| `tail` | `still` / `wag` / `glow` | 尾巴状态 |

高度 212（含耳），局部原点在脚底中心，最宽约 ±100（含尾巴）。

### 简化原则

改版前是「十几个半透明图层叠出来的狐狸」，换个角度就得重画一遍。
现在是**一个剪影、三个色块、不叠半透明层**，形体只用 6 个图元：

| 部件 | 图元 | 说明 |
|---|---|---|
| 尾 | 1 个填充叶形 + 1 个金色椭圆 | 末端金色亮毛 = 知识点亮的信号灯 |
| 身 | 1 个对称梨形 | 正面/背面同形，侧面收窄 |
| 胸 | 1 个奶油色形 | 背面不画 |
| 腿 | 2 个圆角柱 | 侧面时前后错开 |
| 头 | 1 个圆 + 2 个三角耳 | 背面用暗色、不画五官 |
| 口鼻 | 1 个奶油椭圆 + 1 个鼻三角 | 侧面收成一个锥 |

### 四视角差异（`XI_VIEW` 表）

| view | 身宽 | 头 x 偏移 | 口鼻偏移 | 眼睛 | 用途 |
|---|---|---|---|---|---|
| `front` | 52 | 0 | 0 | 两只，等大 | 对话、面对镜头 |
| `q34` | 48 | +8 | +26 | 两只，远侧 0.72 倍 | 最常用，有立体感 |
| `side` | 40 | +15 | +36（锥形吻） | 一只，远侧耳缩到 0.7 | 走位、看远处 |
| `back` | 52 | 0 | — | 无 | 走开、结尾、背影杀 |

**做新视角**：在 `XI_VIEW` 加一行，`hx`（头横向偏移）、`mu`（口鼻偏移）、`eyes`（每个眼的 `[dx, 缩放]`）、
`tail`（尾巴基点 x/y 与旋转角）就够了，形体代码不用动。

### 表情矩阵

只动三处：**眼 / 嘴 / 耳**。

| expr | 眼 | 嘴 | 耳 | 用在哪 |
|---|---|---|---|---|
| `idle` | 圆点 + 高光 | 小弧线 | 平 | 常态 |
| `happy` | 弯弧（闭眼） | 上扬小嘴 | 平 | 同意、开心 |
| `giggle` | 弯弧 | 张口 + 舌头 | 平 | 咯咯笑，配 `vox_trill` |
| `wow` | 大圆眼 | 小 o | 竖起 | 惊讶，配 `vox_yip` |
| `think` | 一只眯 | 波浪嘴 | 后压 | 歪头想，整颗头转 -7°，配 `vox_coo` |
| `scope` | 一只（另一只被镜筒挡） | 小弧 | 平 | 掏望远镜 |

4 种眼 × 4 种嘴 × 2 种耳 ≈ 32 种组合，够一季用。

### 尾巴三态

| tail | 画面 | 触发的音效 |
|---|---|---|
| `still` | 静态 | 无 |
| `wag` | 引擎里左右摆（±8°，1.6Hz） | 无 |
| `glow` | 尾尖金色椭圆 + 径向光晕 + 三颗星 | `vox_insight.wav`（上行四音知识音） |

`glow` 是这个系列的招牌信号，**只在"知识点亮了"的时候用**，一集 4–6 次，用多了就不值钱。

## 动画句柄

每个 `build` 函数返回的 `<g>` 上挂三样东西，引擎靠它们做逐帧动画：

```js
g.__mouth   // 嘴 <g>，说话时纵向压缩（原点 = 嘴心）
g.__eyes    // 眼 <g>，眨眼时压缩到 0.1
g.__tail    // 尾 <g>，摇摆
```

拿不到句柄也不影响静态渲染——这两条是给 `engine.html` 的 `talk` 场景用的。

## 精确矢量 vs Rough.js 手绘

**默认是精确矢量**。手绘档是覆盖层：同一个 `el()` 出口换成 Rough.js，几何一点不改。

```bash
python3 scripts/build.py script.json --rough          # 开手绘档
python3 scripts/build.py script.json                  # 关（默认）
```

seed 是固定的常量（`ROUGH_SEED = 20261116`，在 `engine.html` 顶部），
保证「同一份台本、任何一次运行、每一帧的抖动完全一致」——否则线条会"烧开水"。
要换抖动形态：`engine.html?seed=123`。

三条硬约束（详见 `pitfalls.md`）：

1. 填色层精确、描边层手绘（一次调用同时给 fill+stroke 会露底）
2. 大形体 `roughness` 必须压到 2 以内（否则整条曲线往里缩、露出内轮廓）
3. 渐变填充不参与手绘
