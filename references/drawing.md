# 画面精度：怎么把东西画“细”

> 结论先行：**粗糙不是模型能力问题，是图元数量问题。**
> 图标 5–15 个 shape 就够；插画 50–500+。一张占满屏幕的动物只用了 20 个图元，
> 本质就是“把图标放大”，怎么看都假。

## 一、五层法

任何一张要撑满屏幕的 figure，按这五层叠，**每层单独一个 `<g>`**：

| 层 | 画什么 | 图元量 | 要点 |
|---|---|---|---|
| ① 底色 | 主色大块 + 环境色 | 1–3 | 用渐变，别用纯色平涂 |
| ② 大形 | 闭合贝塞尔轮廓（身体、头、腿） | 5–10 | **不许用 ellipse/rect 拼轮廓** |
| ③ 明暗 | 背光面、腹部反光、投影 | 5–15 | 2–3 层透明色叠加，不要只有“亮/暗”两档 |
| ④ 纹理 | 条纹、毛流、斑纹、鳞片 | 30–80 | 必须 `clip-path` 裁进轮廓，不能溢出 |
| ⑤ 细节 | 眼、鼻、口、须、爪、耳内 | 20–40 | 只画在焦点区，密度最高 |

合计 **80–150 个图元** 才算“画过”。低于 50 个，一眼就是贴纸。

## 二、四条硬规矩

1. **轮廓用 path**。`M … C … Z` 闭合曲线。身体要有起伏（肩、胯、腰），
   不是一根光滑的椭圆。边缘再加一圈毛流（10–20 根短线），破掉几何感。
2. **体积用渐变**。同一块肉色至少 3 个色阶：受光、本色、暗部。
   `K.grad("id", [[0,亮],[0.55,本色],[1,暗]])`，2–3 个 stop 就够。
3. **纹理要裁**。条纹、斑纹用 `K.clipTo("clipX", 轮廓d)` 裁进身体，
   否则会像“贴在身上的贴纸”或直接飘到外面。
4. **焦点加密度**。眼睛要有眼白、虹膜、竖瞳、高光、眼线五件套；
   鼻子要有鼻梁阴影和鼻孔；嘴要有口角。远景背景反而要减，形成对比。

## 三、代码骨架

```js
const fur = K.grad("furTiger", [[0, "#F2A54F"], [0.55, "#E08A2E"], [1, "#B9641A"]],
                   { x1: 0, y1: 0, x2: 0, y2: 1 });

K.figure("虎", (g) => {
  const L1 = el("g", {}, g);          // 底色
  const L2 = el("g", {}, g);          // 大形
  const L3 = el("g", {}, g);          // 明暗
  const L4 = el("g", { "clip-path": K.clipTo("clipTiger", BODY_D) }, g);  // 纹理
  const L5 = el("g", {}, g);          // 细节

  el("path", { d: BODY_D, fill: fur, stroke: "#3A1E0E", "stroke-width": 4 }, L2);
  el("path", { d: BELLY_D, fill: belly, opacity: 0.95 }, L3);
  for (let i = 0; i < 8; i++) { /* 条纹 */ }
  for (let i = 0; i < 20; i++) { /* 毛流 */ }
```

## 四、自检

- 缩到 **300px 宽**，还能看出是虎不是猫吗？
- 关掉所有 fill 只看轮廓，形体站得住吗？
- 边缘是光滑几何线吗？是 → 加毛流。
- 图元数 < 50 吗？是 → 没画完。

## 五、常见敷衍手法（禁止）

| 敷衍 | 后果 |
|---|---|
| 椭圆当身体、矩形当腿 | 一眼贴纸 |
| 一个圆当脸，两个点当眼 | 表情空洞，孩子代入不了 |
| 纹理不裁剪，直接画在轮廓外 | 像贴纸掉在画面上 |
| 全身一个色 | 没有体积，像剪影 |
| 背景画得比主体还细 | 视觉焦点跑掉 |
