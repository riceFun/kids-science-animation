# 视觉素材库

引擎是「场景类型 × 场景」两轴组合：场景类型在 `assets/engine/engine.html` 里固定，**场景（世界）由每集自己的 `scenery.js` 现场画**。台本只写名字。

## 场景类型（SCENES）

| 类型 | 用途 | 动效 |
|---|---|---|
| `title` | 片头／**封面**：左侧两行标题 + 右侧封面主体（`cover`） | 主体淡入上浮、标题轻推入 |
| `talk` | 对话：角色 + 气泡/字幕 | 说话方点嘴 + 轻微起伏，另一方压暗 18% |
| `show` | 讲知识的主画面：**必须给 `figure`**（画这一段讲的那个东西）+ 顶部标题 | 图形淡入上浮 |
| `card` | 知识卡：标题 + 3–4 条要点 | 卡片淡入、每条从左侧滑入 |
| `quiz` | 三选项测验 | 选项逐条滑入、揭晓时正确项描粗变绿并打勾、其余压暗 |
| `outro` | 结尾：只有告别卡 | 卡片弹性缩放入场、角色晃动；`next` 不填就不画蓝条 |
| `figure` | 具体对象单独绘制（不套圆盘） | 由本集 `scenery.js` 的 `figure()` 决定；默认淡入上浮 |
| `photo` | 实拍图铺满全屏 + 右上角署名 | 缓慢推近/拉远（Ken Burns）、暖色软光、暗角 |
| `credits` | 图片来源卡（自动生成） | 卡片淡入、条目逐行上浮 |

场景里所有时间都相对段首：`tt` 是段内秒数，`u` 是段内进度（0→1）。要加新场景，就在 `SCENES` 里写一个 `{ mount(host, seg) { ...; return (tt, u) => {}; } }`。

### 景别（shot）

同一套图元，靠景别制造"镜头在动"的感觉：

| `shot` | 效果 | 适用范围 |
|---|---|---|
| 不写 | 中景，角色全身 + 背景 | 全部 |
| `close` | 镜头推到脸上：角色放大 3 倍、脚底推出画面，只留头肩；气泡自动移到头顶 | 仅 `talk` |
| `macro` | 已废弃（原先把圆盘推到满屏） | — |

`close` 靠的是 `feet = 470 + 450 × scale` 这个关系：450 是角色眼睛在自身坐标系里的高度，
把脚底推到画面下方，眼睛正好落在 470。换角色（考考 / 小熹）要按各自 scale 重算。

**别连续四段同一景别**——`build.py` 会提示。一集里 `close` / `macro` 各来 2–3 次比较舒服。

## 场景：每集现场画（不做背景库）

**没有背景库，也没有「话题 → 背景」映射表。** 每一集讲什么话题，就为它现场用代码画什么世界：
讲太空就画星空和行星，讲蚂蚁就画泥土剖面和根须，讲食物就画厨房台面。
台本里的 `bg` 只是这段场景的名字，名字背后是本集 `scenery.js` 里的绘制函数。

### 怎么接上

每集目录放一个 `scenery.js`，用 `SCENE_KIT.scene()` 注册：

```js
const K = window.SCENE_KIT;

K.scene("星空", (root, seg) => {
  K.el("rect", { width: K.W, height: K.H, fill: "url(#gSpace)" }, root);
  for (let i = 0; i < 150; i++) {
    K.el("circle", { cx: K.rnd(i * 3.1) * K.W, cy: K.rnd(i * 7.7) * 700,
                     r: 1 + K.rnd(i * 2.3) * 2.5, fill: "#FFF", opacity: 0.7 }, root);
  }
  const p = K.el("circle", { cx: 1500, cy: 300, r: 170, fill: "#8E6CC4" }, root);
  return (t) => { p.setAttribute("r", 170 + Math.sin(t) * 4); };  // 可选：每帧更新
});
```

台本里写 `"bg": "星空"` 即可。`build.py` 会自动把同目录 `scenery.js` 注入渲染器，
并在时间线阶段校验名字——**写错名字会报警**，不会静默退回默认背景。

**`scenery.js` 改了会自动触发全量重渲**（脚本内容进帧签名），不用担心旧帧残留。

### 什么时候该画新场景

一段文案在讲什么，画面就该在哪：

| 文案在讲 | 画什么 |
|---|---|
| 「蚊子顺着气味飞过来」 | 夜色草丛 + 一条飘动的气味曲线 |
| 「蚁后在土里产卵」 | 泥土剖面 + 根须 + 卵粒 |
| 「蝴蝶从蛹里钻出来」 | 树枝 + 半透明蛹壳 + 光斑 |
| 「太空里没有空气」 | 星空 + 行星 + 漂浮的小石子 |

**判据：如果这段画面换个话题也能用，说明它画得还不够具体。**

### 可用的画具（SCENE_KIT）

| 成员 | 作用 |
|---|---|
| `el(tag, attrs, parent)` | 建 SVG 节点（`rect`/`circle`/`path`/`g`/`text`…） |
| `txt / wrapTxt` | 写字 / 自动折行 |
| `rnd(seed)` | 确定性随机，同一 seed 永远同值（保证帧可复现） |
| `nearSil(root, kind, color, op)` | 前景剪影：`grass` / `branch` / `kelp` / `coral` |
| `faceKit(g, x, y, r, expr)` | 给物体按眼睛和嘴（`shock` / `smile` / 默认）。让瓶子、冰块、蚊子"活"起来 |
| `clamp / lerp` | 数值工具 |
| `W / H` | 1920 / 1080 |
| `INK / CREAM` | 主色：`#3A2A1C` / `#FDF4E2` |
| `G.*` | 常用渐变 id（`G.skyDay`、`G.storm`、`G.gold`…） |

### 三条硬要求

1. **必须返回 `update(t)`**（或返回 `null`）：视差、闪烁、飘动都靠它，静止画面像 PPT。
2. **必须给光源**：画完在函数上挂 `.light = {x, y}`，主光光晕会移过去；不挂就用默认左上，容易和画面里的太阳打架。
3. **暗场景要压后期**：`fn.prof = {grade, vig}`。亮场景（草地、雪地）用重档会发脏。

> 引擎里还留着 `meadow_day` 等几个旧背景，只为兼容早期几集，**新的一律自己画**。

## 符号（EMBLEM）——已废弃

原来 `show` 用「大圆盘 + 一个通用图标」，`card` 每个要点前再挂一个图标。
问题是这些符号和文案没有关系：讲玻璃鳗也用水滴、讲苗价也用太阳，最后每集长得一样。
**现在不再渲染 emblem / icon**，具体东西一律用 `figure` 画，或上 `photo` 真图。
`EMBLEM` 表还留在引擎里，但没有调用点。

## 排版安全区

1920×1080，出片会进竖屏裁切的话，重要内容收在中间 1400px 内。

| 区域 | y | 用途 |
|---|---|---|
| 96–250 | 顶部 | 标题条、问题条 |
| 260–860 | 中部安全区 | 主体内容 |
| 900–1030 | 底部 | **字幕专用**，不要放正文 |
| 角色脚底 | 950（默认） | `castChars` 的 `feet` |

字幕两条基线固定 958 / 1026，字号 52。所以 `card` 底边不能超过 880，`show` 的大标题基线在 `cy+340`（约 840）。

## 角色站位

`castChars` 默认：考考 x=520 scale 0.92，小熹 x=1340 scale 1.34，脚底 y=950。

- 考考全高 560（scale 1 时），发尖到 -590
- 小熹全高 210，尾巴向左后方扫出，尾尖在 -158 附近
- 两人放一起时，间距至少 300，否则小熹会挡在考考身前

## 景深（近 / 中 / 远三层）

一张背景如果只有"天空 + 一层地面"，看久了就是壁纸。三层才立得住：

| 层 | 做法 | 关键约束 |
|---|---|---|
| **远景** | 比中景淡 2 档、位置更高的山/树/水草 | 颜色向天空靠拢（夜间是更亮更蓝，不是更暗） |
| **中景** | 原来的主体地形 | — |
| **近景** | `nearSil(root, kind, color, op)`：两侧草丛、上角树枝、水草、前景细胞 | 颜色比中景暗 2–3 档；**只放两侧和底部 70px 内**，中间留空给角色 |

- 每个场景在末尾调 `nearSil`，`kind` 可选 `grass` / `branch` / `kelp` / `coral`。
- 草叶尖端要留 `w*0.14` 的宽度（收成窄边），收成一个点会整丛变仙人掌。
- 前景要放在`闪光层之下`（storm），这样闪电时前景也被照亮。

## 光源对齐

每个场景必须声明 `.light = { x, y }`（太阳 / 月亮 / 窗 / 洞口的位置），`ATMO.key` 光晕会移过去。不声明就用默认左上——和画面右上角的太阳打架，一眼假。

| 场景 | light |
|---|---|
| 户外有太阳/月亮 | 对齐日月坐标，如 `1600,175` |
| 室内有窗 | 对齐窗中心，如 `1420,300` |
| 地底 / 微观 / 星空 | 光源在上方：`960,60` 一带 |
| 夜晚只有月光 | 月光坐标，`prof` 同时压到 0.28 左右 |

> 早期几集的 `meadow_day` 等内置背景保留着，只为兼容；新的一律在 `scenery.js` 里自己声明。

## 文字在框内的垂直居中

SVG 的 `y` 是**基线**不是中心，所以"看着居中"的数值写死必然会偏。公式：

```
基线 = 框中心 + 字号 × 0.35 − (行数 − 1) × 行高 / 2
```

多行时先 `wrapTxt` 拿到行数再回写 `y`：

```js
const lines = wrapTxt(head, text, 960, centerY, 62, color, 700, 18, 68, "middle");
const base = centerY + 62 * 0.35 - (lines.length - 1) * 68 / 2;
lines.forEach((t, i) => t.setAttribute("y", base + i * 68));
```

**踩过的坑**：quiz 题头曾写死 `y=152`，而框中心在 171——题目贴着上沿、下面空一大截。凡是"框 + 单行字"的地方都按这个公式验一遍。

## 对话气泡（talk）

**跟着说话者走，不要横在画面中央**——这是最容易毁画面的地方：一句 20 字的话配 1280 宽的气泡，等于把背景盖掉一半。

| 参数 | 值 |
|---|---|
| 宽度 | `clamp(字数*40+130, 340, 780)`，长句自动折行 |
| 高度 | `96 + 行数*54`（单行 150，双行 204） |
| 位置 | 说话者在左 → 中心 `452`；在右 → `1468`（可用 `sayX/sayY` 覆盖） |
| 字号/行高 | 42 / 54 |
| 每行字数 | `floor((宽-70)/42)` |

视觉三件：主体（描边 9）+ 左上高光弧（白色 w5 op .45）+ 曲线水滴尾巴（指向说话者）。

入场：从说话者那一侧偏移 24px、`scale 0.86→1`，用 `easeBack` 弹进来。

## 角色动作（四层叠加）

只做上下浮动会像"两个假人"。四层错相位叠加，才有生命感：

| 层 | 做法 | 幅度 |
|---|---|---|
| 呼吸 | 竖向缩放 `1 + sin(t*1.45)*0.006` | ±0.6% |
| 重心 | 以脚底为轴旋转 `sin(t*0.72)*1.0` | ±1° |
| 说话 | 缩放再 +1%、摇摆加快到 `sin(t*3.0)` | 前倾感 |
| 倾听 | 点头：`pow(max(0,sin(t*2.05)),6)*7` 加到 y | 偶尔一下 |

两人相位必须错开（考考 `+0.6`，小熹 `+2.1`），否则同步摇摆一眼假。

## 角色细节

三笔就够，多了显脏：

| 部位 | 做法 |
|---|---|
| 发丝 | 3 条比发色**亮一档**的细弧（`#6E4E34`, w3.5, op .5），顺着发流走 |
| 衣褶 | 腋下两道放射褶 + 腹部一道横褶（`K.hoodieDk`, op .3–.45） |
| 拇指 | 手球侧面一个偏转 24° 的小椭圆，手就从"圆球"变成"能认出是手" |
| 五官 | 已有眼白/瞳孔/高光点/上睑压线/牙齿/舌头，**不需要再加** |

## 镜头（CAMERA）

每段自带缓慢推拉 + 正弦漂移。静止画面显"平"，3–7% 的缩放就能让人感觉镜头在呼吸。

| 场景 | from → to | drift | 用意 |
|---|---|---|---|
| `title` | 1.075 → 1.030 | 9 | 片头落定 |
| `talk` | 1.030 → 1.058 | 6 | 缓慢推近，拉近距离 |
| `show` | 1.030 → 1.075 | 5 | 强调主体 |
| `card` | 1.055 → 1.030 | 4 | 拉远展示全貌 |
| `quiz` | 1.030 → 1.052 | 4 | 轻推 |
| `outro` | 1.060 → 1.030 | 8 | 拉远告别 |

**硬约束**：`from/to` 最小只能到 1.03（再小就和 drift 打架，边缘露白）；`feet` 不超过 1020（否则放大后脚被裁）。

## 氛围（ATMO）

`#atmo` 层在 `#world` 之上、`#post` 之下，所以会被暗角一起压住。四样东西：

| 元素 | 作用 | 参数 |
|---|---|---|
| `key` | 左上主光光晕，画面"有光源" | `KEY_OP[bg]`，暗场景 0.75–0.8，室内 0.4 |
| `haze` | 地面薄雾，远景和地面之间垫空气 | `HAZE_OP[bg]`，室内 0，深色场景 0.2 以内 |
| `bokeh` ×5 | 光斑缓慢横漂 | `ATMO_OP[bg]`，浅色 0.06–0.1，深色 0.2–0.25 |
| `dust` ×22 | 浮尘向上循环 | 同上 ×1.15 |

**别贪多**：`meadow_night` 背景自带萤火虫，`ATMO_OP` 给 0.15 就够，再高整屏都是泡泡。

## 质感四件套

1. **角色同色系渐变**：`chars.js` 里 `CG` 表把主要色块（皮肤/头发/卫衣/裤子/鞋/狐狸毛色）的纯色填换成了「左上亮 → 右下暗」的渐变，`ensureGrads()` 自动注入 `<defs>`。
   - 用 `objectBoundingBox`（默认坐标系），每个元素各自从自己的左上过渡，所以角色跑到画面任意位置、任意缩放下光照方向都对。
   - 这是 SVG 里做体积感最便宜的手段。纯色块在深色背景上一眼就是剪纸。
   - 想调明暗差就改 `CG` 两端的 hex：亮端往白提 8–12%，暗端往黑压 12–18%。
2. **接地阴影**：每个角色两层——接触阴影（`#000` op .2，紧贴脚底）+ 环境阴影（`url(#gShadow)`，大而淡）。只铺一层的话，深色地面看不见、浅色地面像脏斑。
3. **色彩分级**：`#world` 上挂 `filter: saturate(.93) contrast(1.06)`。平涂卡通靠这一步才有"调过色"的质感，成本几乎为零。
4. **柔和投影**：卡片/圆盘的投影必须模糊（`filter: blur(20px)`）或径向渐变。硬边矩形偏移出来会被看成"卡片右侧多了一道厚边"。

## 后期

两层，都在 `#post` 里：

- `postGrade`：暖橙 overlay，强度取当前场景 `prof.grade`
- `postVig`：暗角，强度取 `prof.vig`

跨场景切换时按透明度加权混合，所以从一个亮场景切到夜间场景，后期是平滑过渡的。

胶片颗粒**不在 SVG 里**——交给 `ffmpeg` 的 `noise` 滤镜在编码时叠（`--grain` 开关）。
